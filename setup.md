# Al Mecca Hotel and BBQ — Setup & Deploy Guide

Generated by Agent Factory v1. This kit is a **DRAFT** — review it, fill in
the real values in `checklist.md`, then deploy. The factory never deploys
anything by itself.

## 1. What this kit is

- **WhatsApp chatbot** (`al-mecca-hotel-and-bbq_bot.py`): FastAPI + Twilio WhatsApp + Gemini
  order parsing + Google Sheets. Greetings show the menu and never create
  an order. Prices come ONLY from `al-mecca-hotel-and-bbq_config.json`.
- **Inbound calling agent** (`al-mecca-hotel-and-bbq_calling_agent.py`): Twilio Voice,
  takes delivery orders by phone, same menu / Sheet / alerts.

Channels in this kit: whatsapp, calling

## 2. Fill in real values (see checklist.md)

1. Edit prices ONLY in `al-mecca-hotel-and-bbq_config.json` — never in the `MENU` dict
   inside the `.py` files (the JSON overwrites it at startup).
2. Copy `.env.template` to `.env` and fill in: Twilio SID/token, WhatsApp
   sender number, Gemini key, kitchen + owner WhatsApp numbers, admin
   password. Never commit `.env`.
3. Share the Google Sheet named "Al Mecca Hotel and BBQ" with the service
   account email, and paste the service-account JSON into
   `GOOGLE_CREDENTIALS_JSON` on Railway (never in chat or GitHub).

## 3. Deploy on Railway (from GitHub)

1. Create a GitHub repo and upload these files (never `.env` or
   `credentials.json`). Add a `.gitignore` that ignores `.env`.
2. Railway → New Project → Deploy from GitHub → pick the repo.
3. Start commands (use `$PORT`):
   - WhatsApp bot service: `uvicorn al-mecca-hotel-and-bbq_bot:app --host 0.0.0.0 --port $PORT`

   - Calling agent service (second service, same repo): `uvicorn al-mecca-hotel-and-bbq_calling_agent:app --host 0.0.0.0 --port $PORT`

4. Railway → Variables: paste every value from `.env` (see list above).
5. Railway → Settings → Generate Domain. Put the domain in `SERVER_URL`
   (e.g. `https://your-app.up.railway.app`) and redeploy.
6. Check `<domain>/health` — it must return `{"status": "ok", ...}`.

## 4. Connect Twilio

- WhatsApp: Twilio → Messaging → WhatsApp Sandbox (testing) or your
  WhatsApp sender (live) → "WHEN A MESSAGE COMES IN" → `<domain>/whatsapp`.
- Voice (calling agent): Twilio → Phone Numbers → your voice number →
  Voice webhook → `<calling-agent-domain>/voice`.
- For sandbox testing, join the sandbox from a phone first (membership
  lasts 72 hours).

## 5. Test before going live

1. Send "Hi" → you must get the welcome + menu, and NO order is created.
2. Send "2 chicken biryani, 1 naan" → totals must come from the config
   menu (food + delivery charge), then name → address → phone.
3. Check the kitchen + owner WhatsApp alerts and the Google Sheet row.
4. Calling agent: call the Twilio voice number, order by voice, confirm
   with "yes", check the Sheet row and alerts.
5. Offers: owner sends
   "Offer <text>" or a banner image → text/banner reach EVERY customer
   who ever ordered (no subscribe step). Owner sends "CallOffer <text>"
   → the calling agent calls every customer and speaks the offer (needs
   TWILIO_VOICE_NUMBER; CALLING_AGENT_URL optional — when set, the
   calling agent serves /offer-call, otherwise the bot serves it). No
   subscribe/unsubscribe — every known customer gets the offer.

## 6. Going live (later, separate step)

- Buy a Twilio phone number, register it as a WhatsApp sender (Meta /
  WhatsApp Business approval), and set it as `TWILIO_WHATSAPP_NUMBER`
  and `TWILIO_VOICE_NUMBER`.
